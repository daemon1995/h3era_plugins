# Combat_SwitchingCreatureAction

Нажатие ALT или кнопки переключает доступные действия по кругу. Удержание клавиши
не вызывает повторных переключений. Кадр кнопки — **следующее** действие (`ID * 3`),
а выбранный режим, кроме одноразового выбора AoE, хранится отдельно для каждого
стека до конца битвы. При одном
доступном действии переключатель скрыт.

ALT назначен самой DEF-кнопке через `AddHotkey(H3VK_ALT)`. Нажатие обрабатывает
штатная кнопка игры; отдельного опроса клавиатуры в основном интерфейсе нет.

После выбора обновляются сетка и поле боя, сбрасывается сохранённая клетка курсора
и вызывается штатная постановка сообщения движения мыши (`0x4ECCD0`). Во время
действия, автобоя и чужого хода переключение и дополнительные перерисовки запрещены.

Меню ALT + цифра сохранено отдельно в `HeldAltMenu.cpp`, методе
`SwitcherDlgPanel::HandleHeldAltMenu`. Основная процедура боя его не вызывает.

Пара «колдовать на точку / шагать» добавляется, когда найдена пустая клетка
с подходящим союзным трупом, на которую существо может применить способность
и физически переместиться на текущем ходу. Доступность перемещения проверяет
штатный курсор/поиск пути с временно отключённым колдовством. Целевые поля стека
после этой проверки восстанавливаются. Заклинания по живым целям проверяются отдельно.
Если колдовство не конкурирует с движением на клетку с трупом, в режиме CAST
сохраняются штатная ходьба, полёт и шаг назад. Доступность клеток определяет игра;
для колдовства на достижимый труп остаётся отдельное переключение CAST/MOVE.

Требуется исправленный хук шага назад в `game bug fixes extended`: один LoHook
в `0x476020`, без NOP-патча в `0x47601E`. Он сохраняет штатное восстановление
EDI/ESI, поэтому расчёт курсора вызывается обычным `thiscall`.

## Выстрел по площади

Действие 7 доступно живому стеку с флагом площадного выстрела и настроенным типом
выстрела, если он сейчас может стрелять. ALT/кнопка и G вызывают один диалог
выбора цели из `aoe_attack.cpp`. Наведение показывает область поражения в радиусе
одного гекса; ЛКМ подтверждает штатную сетевую команду `SHOOT`.
Целью может быть пустой гекс
или любой стек, включая союзный; выбранная половина двуклеточного стека сохраняется.

Нельзя выбирать собственные гексы, крайние колонки и соседние клетки без лука
снайпера. Подсветка, выбор ИИ и урон используют один настроенный тип выстрела:
огненный взрыв исключает по краям иммунных к огню, облако смерти — неживых,
физический выстрел поражает всех. Прямая цель в центре получает обычный урон.
Двуклеточный стек получает площадной урон один раз. Подсветка снимается при смене
режима, стека и начале действия.
Выстрел, урон по площади, расход снаряда и анимацию выполняют обработчики из
`aoe_attack.cpp`. ESC или ПКМ отменяют выбор без расхода хода. После закрытия
диалога выбран обычный выстрел; AoE не сохраняется на следующий ход.
Во время выбора цели ALT и кнопка продолжают цикл со следующего после AoE
действия. Обрабатывается та же DEF-кнопка с её штатной горячей клавишей;
остальные элементы родительского окна остаются заблокированными.

В режиме AoE область выстрела рисуется штатным слоем тени курсора с учётом
настройки игры. Только на время диалога скрывается тень дальности перемещения;
её маска восстанавливается при подтверждении и отмене. Постоянного режима AoE
и отдельного перехвата обычного наведения/клика нет.
При входе в выбор цели фон один раз собирается из штатного фона местности и
препятствий с пустой маской дальности. При выходе восстановленная дальность
также получает чистый фон. Наведение использует только штатный проход подсветки
без повторной отрисовки всех существ поверх готовой области. Повторные сообщения
над той же недопустимой клеткой не перерисовывают её заново.

Рукопашная команда `WALK_ATTACK` исполняется как рукопашная на обоих клиентах,
не переходя к стрельбе по локальному состоянию кнопки. Флаг стрелка сохраняется,
поэтому двойной выстрел не превращается в двойной рукопашный удар обычного стрелка.
На чужом ходу кнопка отключена и использует нейтральные кадры, включая служебные
кадры отключения и выделения.

### Настройка и комплект WoG

`AreaShotTypes.cpp` переносит типы и расчёт физического площадного урона из
предоставленного исходника `JS_AimedAreaShot`. Урон наносится после единственного
штатного расхода снаряда. Для огня и облака смерти используются нативные ветви
анимации и урона. ИИ оценивает все допустимые гексы штатной функцией оценки,
учитывая вред союзникам; при равном результате выбирает ближайшую цель.

JSON-ключ `jsMod.shotAtArea.creatures.<ID>.type` задаёт тип: `0` — отключён,
`1` — огонь, `2` — облако смерти, `3` — физический. После `OnAfterErmInstructions`
значения копируются в переменные ERA `js_aimedShotType_<ID>`; стрелкам с ненулевым
типом устанавливается флаг площадного выстрела. Изменение переменной ERA во время
игры меняет тип для последующих выстрелов существ с этим флагом.

Начальные значения из приложенного JSON: `45 → 1`, `64/65/196 → 2`, `94/95 → 3`.

Комплект устанавливается целиком в `Mods/WoG`:

- `EraPlugins/Combat_SwitchingCreatureAction.era`;
- `Lang/combat_switching_actions.json` и `Lang/Ru/combat_switching_actions.json` —
  настройки, подсказки наведения и описания по ПКМ для всех действий;
- `Data/icm*.def` — существующие ресурсы кнопок из `choose attack.pac`;
- `DebugMaps/Combat_SwitchingCreatureAction.map/.dbgmap` — символы сборки.

ПКМ показывает описание действия, изображённого на кнопке (следующего в цикле).
Тексты кнопок находятся в `combat_switching_actions.hint.*` и `.rmc.*`.
Прицел использует существующий игровой DEF через штатный `SetCursor`.
После Release-сборки `Install-WoG.ps1` устанавливает DLL, символы, обе локализации
и DEF в WoG, предварительно сохраняя заменяемые файлы в `_build`.

## ERM API

```erm
!?FU(OnStartOrLoad);
!!SN:F^Combat_SwitchingCreatureAction:SetOnBattleStackActionDetermination^/(OnBattleStackActionDetermination);
```

Экспорт `BOOL __stdcall SetOnBattleStackActionDetermination(INT functionId)`
регистрирует один обработчик; `0` отключает его. Возвращает `1` при успехе,
`0` для отрицательного ID. Регистрацию повторяют при старте/загрузке карты.

Обработчик вызывается после штатного определения действий при получении управления
стеком и при пересчёте после завершившегося действия. В автобою, во время анимации
и на обычных сообщениях окна вызова нет.

| Параметр | Значение |
| --- | --- |
| `x1` | ID стека `side * 21 + sideIndex`, 0–41; ID сохраняется при гипнозе |
| `x2` | ID текущего героя владельца, с учётом гипноза; `-1` без героя |
| `x3` | `melee` — рукопашная атака |
| `x4` | `shoot` — обычный выстрел |
| `x5` | `areaShot` — площадной выстрел |
| `x6` | `castEnemy` — колдовство по живому противнику |
| `x7` | `castAlly` — колдовство по живому союзнику, включая самого заклинателя |
| `x8` | `castHex` — колдовство по пустому гексу/трупу, куда отряд может дойти |
| `x9` | `attackReturn` — выбор между атакой с возвращением и атакой без возвращения |

```erm
!?FU(OnBattleStackActionDetermination);
!#VA(stackId:x) (heroId:x) (melee:x) (shoot:x) (areaShot:x) (castEnemy:x) (castAlly:x) (castHex:x) (attackReturn:x);

; Например: запретить обычный выстрел, разрешить доступный площадной.
!!VR(shoot):S0;
!!VR(areaShot):S1;
```

Входные флаги уже содержат текущую физическую доступность (`0` или `1`).
Изменение на `0` исключает вариант, `1` разрешает его при наличии способности,
зарядов, допустимых целей и остальных штатных условий. Любое ненулевое значение
считается `1`. Сохранение входного значения оставляет штатную доступность.

Плагин формирует интерфейс из сочетаний флагов:

- `melee=1`, `attackReturn=0` — обычная рукопашная кнопка;
- `melee=1`, `attackReturn=1` — пара «вернуться / остаться» вместо дублирующей
  рукопашной кнопки; при `melee=0` эта пара также исключается;
- `shoot` и `areaShot` независимы: площадной выстрел доступен и при `shoot=0`;
- любой разрешённый магический флаг добавляет одну кнопку CAST; цели враг/союзник/
  гекс фильтруются отдельно, в том числе при штатном выборе без явного режима;
- `castHex=1` добавляет MOVE для перемещения на достижимый гекс без воскрешения;
- магия только по живым целям сохраняет обычную ходьбу/полёт в режиме CAST;
- при одном варианте переключатель скрывается; флаги рукопашной, стрельбы и магии
  учитываются при расчёте штатного курсора и в этом случае;
- AoE остаётся одноразовым выбором; после отмены возвращается обычный выстрел,
  если `shoot=1`, иначе штатный выбор из оставшихся разрешённых вариантов.

Сначала вычисляются нативные возможности, затем вызывается ERM, после чего
собирается список режимов. Порядок режимов определяет плагин. Значения внешних
`x1..x16` аргументов и результатов сохраняются и восстанавливаются вокруг вызова.
Во время исполнения боевых команд действуют штатные игровые проверки.

Это новый формат параметров: прежние `actionCount` и `actions[]` заменены флагами.
Пример без изменения штатных возможностей, с отдельно отключёнными примерами
назначений — `BattleStackActions.erm`.
