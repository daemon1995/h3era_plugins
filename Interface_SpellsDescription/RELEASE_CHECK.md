# Подготовка Interface_SpellsDescription к релизу

Проверка 03.10.2026 охватывает исходники расчёта, книгу, боевые хуки,
подсветку, внешний API, ERM-интерфейс, локализацию и конфигурацию сборки.

## Изменения

- Общая таблица JSON-ключей и printf-сигнатур в `SpellDescriptionTranslations.h`
  используется описаниями и подсветкой. Переводы читаются без кэша.
- Типы длительности ERM 1/5/6 используют один шаблон `duration.rounds`;
  пояснения о снятии эффектов отсутствуют. ABI фаз и значения типов сохранены.
- Книга рассчитывает бонусы героя только для поддерживаемого численного
  описания; призыв рассчитывается один раз по своей формуле.
- API отклоняет запросы для завершённого/скрытого боя и неверной действующей
  стороны. Некорректные гексы и вложенные запросы не выполняют расчёт.
- Очистка подсветки сравнивает целую строку пикселей и копирует её за один
  проход, если она не изменилась. Частичные обновления сохраняются целыми
  16/32-битными пикселями. Буферы освобождаются между боями и при выходе.
- Предельные значения формулы жертвы насыщаются до int64 вместо переполнения.
  Выбор следующей цели цепи не преобразует огромную дистанцию в int.

## Сборка и ресурсы

- Release x86, общие параметры из `Directory.Build.*`, проверка с `/W4`.
  В общих заголовках H3API/ERA остаются предупреждения уровня 4; собственные
  исходники плагина собраны без предупреждений по журналу компилятора.
- В исходниках нет диагностического логирования и дополнительных отладочных хуков.
- Проверка всех 27 EN/RU текстовых ключей и булевой настройки MR1 и printf-сигнатур непосредственно в моде:
  `tools/validate_spell_texts.py --game-dir <путь к игре>`.
- JSON хранится только в `Mods/WoG/lang` и `lang/ru`.

Локальный сравнительный тест очистки: 3000 кадров, 10 клеток, RGB565/RGB32,
неизменённый слой и смешанные нативные/нарисованные пиксели. Зафиксировано
ускорение около 5–10 раз. Это результат операции очистки на данной машине,
а не измерение производительности или частоты кадров всей игры.

## Состав установки

- `EraPlugins/Interface_SpellsDescription.era` — Release PE32.
- `lang/interface_spells_description.json` — базовый английский перевод.
- `lang/ru/interface_spells_description.json` — русский перевод.
- `DebugMaps/Interface_SpellsDescription.map` и `.dbgmap` из той же сборки.

Не подключать одновременно старый `Spells_Description` или другую копию
того же плагина. Примеры ERM подключаются только по необходимости модом;
пример изменения длительности отключён комментариями.

## Проверка в игре перед публикацией

Ранее пользователь подтвердил MR0/MR1 и устранение исчезновения подсветки.
После текущего рефакторинга требуется проверить в игре книгу по ПКМ,
одиночный и площадной урон, цепь с двухгексовыми существами, смену цели,
ESC и реальный каст, обе стороны боя, повторное наложение баффа,
воскрешение, жертву, английский/русский язык и новый бой после старого.

Прогноз восстанавливает контролируемые поля действия, MR и аргументы ERA;
сторонние изменения состояния внутри ERM не откатываются транзакционно.
Остальные модификации отрисовки и нестандартная геометрия клеток требуют
отдельной проверки совместимости.

## Режим MR0 по умолчанию (15.10.2026)

MR1 при прогнозе отключён. Один LoHook в 0x75D964 пропускает только
вызов ERM MR1 и очистку его аргумента до выполнения push, сохраняя MR0,
нативное сопротивление/опыт и последующую защиту. При реальном касте
MR1 выполняется независимо от настройки. JSON boolean
`interface_spells_description.settings.enableMr1Preview` включает MR1
только для прогноза; по умолчанию false. Описание EN/RU рядом с настройкой
указывает условие `i^era.opt.spells.preview^ = 0` для побочных действий.

Проверены 40 000 вызовов производственного LoHook на синтетическом конвейере
с установленным patcher_x86.dll: все сочетания прогноз/реальный каст и
включённый/выключенный MR1, сохранение MR0 и последующей защиты, результаты
и баланс ESP. Проверены missing/false/true/0/1 и неверные значения настройки.
Тест не запускает игровой бой; нативная последовательность дополнительно
сверена по дизассемблированию h3era.exe.
