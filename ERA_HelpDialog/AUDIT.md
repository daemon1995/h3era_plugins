# Аудит ERA_HelpDialog

Проверены исходники плагина, владение ресурсами, оба общих языковых файла и справка модов из профиля `ERA Project - full.json`. Подготовленные данные ограничены этим профилем; русификаторы исключены.

## Владение объектами

| Объект | Владелец | Освобождение |
| --- | --- | --- |
| Нативные элементы диалога, включая рамки, кнопки, редактор, hint bar и прокручиваемый текст | Родительский `H3Dlg` | Нативный деструктор элементов в `H3Dlg::~H3Dlg`; страницы их повторно не удаляют. |
| Копия 16-битного фона диалога | `H3Dlg` | `background->Destroy()` в базовом деструкторе. |
| Временный canvas `AddSafeBackground` | Локальная функция | `Destroy()` сразу после копирования в фон диалога, включая ошибку добавления. |
| `ERAHDSLT.PCX`, общий фон селекторов | `MainDlg::selectorBackground` | Конструкторы `TextPcx` получают свои ссылки. Деструкторы страниц/выпадающих списков освобождают их и обнуляют указатели; затем `MainDlg::~MainDlg` снимает ссылку владельца. |
| `ERAHDBAR.PCX` | `MainDlg::hintBackground` | Сначала отсоединяется hint bar, затем снимается ссылка владельца в `MainDlg::~MainDlg`. |
| `ERAHDSRH.PCX`, строки поиска | `SearchPanel::rowBackground` | Деструктор отсоединяет все строки, затем освобождает изображение. |
| `ERAHDEDT.PCX`, изображение поля поиска | Локальный `H3PcxLoader` в конструкторе шапки | Изображение копируется в основной фон и освобождается локальным деструктором загрузчика. Элементы ввода его не заимствуют. |
| Загруженные PCX портретов | `CatalogueSection::portraitCache` | Указатели `H3DlgPcx` обнуляются, затем освобождаются ссылки кэша. |
| Загруженные DEF/шрифты/текстуры и временный canvas проверки артефактов | Локальные H3-загрузчики | Их деструкторы снимают ссылки; нативные элементы держат собственные ссылки на ресурсы. |
| Страницы, каталоги и данные модов | `MainDlg`, `ModInformation`, `Category` | Страницы удаляются перед данными модов; `Category` имеет виртуальный деструктор и удаляет `Content`. |
| Тексты ERA JSON | ERA | Постоянные заимствованные указатели. Сформированные строки копируются в нативные текстовые элементы; `SetHints(..., true)` используется для временных подсказок. |

Для ресурсов менеджера используется `Dereference()`: снятие последней ссылки удаляет ресурс из менеджера и уничтожает его. Прямой `Destroy()` такого PCX при живых ссылках элементов был бы ошибкой. После `Release()` указатель H3-загрузчика пуст, поэтому его собственный деструктор не освобождает ресурс второй раз.

Все классы диалогов плагина (`MainDlg`, `GuideDlg`, `ModListDlg`, `ChoiceListDlg`) имеют виртуальные деструкторы. Базы страниц и секций также имеют виртуальные деструкторы. У SDK-класса `H3Dlg` деструктор не виртуальный; менять его ABI нельзя. Производные диалоги объявляют собственный виртуальный деструктор без `override` и не удаляются через указатель `H3Dlg*`. ABI классов H3API не изменялся.

Сверены объявления/реализации H3API и локальные экспорты `BinaryTreeItem_Ctor__558970`, `DlgTextPcx_Ctor__5BCB70`, `LoadPCX__55AA10`. Создание зарегистрированного PCX оставляет одну ссылку владельца; загрузки `TextPcx` учитываются отдельно. Старый SDK-wrapper `AddToResourceManager` здесь не используется: в запись дерева передаётся и имя, и указатель ресурса.

Это статическая проверка владения и успешная компиляция, а не измерение памяти работающей игры. Повторное открытие/закрытие, смену размера и переключение страниц с контролем счётчиков ресурсов нужно проверять в игре.

## Тексты и горячие клавиши

В пакете оставлены описания WoG, ACM, GEM и TrainerX на английском и русском языках. Источники каждого мода перечислены в `content/mod-help-sources.json`: сначала читается `mod.json`, затем указанные в нём файлы описания.

Исправлено:

- W/E и другие сочетания классов относятся к Advanced Classes Mod, а не WoG.
- Цифровое меню выбора действия существа удалено из справки: `HeldAltMenu.cpp` прямо отмечает, что основной обработчик его не вызывает. Переключение Alt остаётся.
- Команды интерфейсных плагинов больше не приписаны ERA Scripts без подтверждённого источника.
- Из GEM удалены две записи загрузки в бою: текущий `gem_scripts.erm` содержит обработчик Ctrl+L только для карты приключений. Боевое L описывается в разделе HD-мода; боевое Ctrl+L не заявляется.
- Команды Unleashed Editor явно помечены как команды редактора карт. Команда Ctrl+F9, отмеченная автором как доступная только в SoD, в игровой пакет ERA не добавлена.
- Удалена ссылка на постороннее руководство издателя и связанные с ней пояснения. Удалены девять общих заметок о городах, повторявших уже показанные данные карточки.
- Поле отсутствующего имени мода использует имя папки; это поведение отражено в инструкции.

Дополнительные источники GEM: `gem_scripts.erm`, `gem_town_menu.erm`, `Protection by all units in battle.erm`, `GameplayFeature.cpp`, `AdventureMapHints.cpp`, `Interface_ArtifactsQuickSwitching/dllmain.cpp` и исходные описания установленного мода. Совпадающие клавиши разных экранов сохранены как разные записи.

В `gem_settings.erm` остаются собственные обработчики F1 для четырёх игровых экранов. `ERA_HelpDialog` также перехватывает F1. Это потенциальное пересечение между двумя обработчиками; порядок их работы в запущенной сборке здесь не проверялся. Скрипт GEM в рамках этого аудита не менялся.

Общие игровые сочетания просмотрены по контекстам; это не новые назначенные клавиши. Действия fan HD-мода сверены с [документацией автора](https://sites.google.com/site/heroes3hd/eng/functionality) и [настройками](https://sites.google.com/site/heroes3hd/eng/tweaks). Это отдельный мод для Complete/ERA. Работа функций зависит от версии и настроек, а GEM может переопределять некоторые клики.

## Границы пакета

- Не создавались записи для Advanced Classes Mod Rus, WoG Rus и WoG Scripts Rus.
- Для Era Erm Framework поставленный файл содержит только название; отдельная пустая статья не создаётся.
- У Random wallpaper файлы описания из `mod.json` отсутствуют. Краткое описание основано только на названии мода и существующем `Lang/random_wallpapper.json`; горячие клавиши не придуманы.
- Остальные папки вне профиля не изменяются.

Инструкция: `AUTHORING.md`. Установщик `Install-ModHelp.ps1` размещает 32 файла описаний и 2 файла общего интерфейса в выбранной игровой папке; старые файлы сохраняет в `build/content-audit/backups`.
