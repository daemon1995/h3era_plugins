# Как добавить справку своего мода

## Файлы и ключ папки

Создайте два файла с одинаковым именем:

- `Mods/My Mod/Lang/my_help.json` — английский текст.
- `Mods/My Mod/Lang/ru/my_help.json` — русский текст.

Сохраняйте JSON в UTF-8. Ключ `my mod` — реальное имя папки мода в нижнем регистре. Имя файла произвольное; не копируйте целиком общий `era_help.json`: он содержит переводы интерфейса и чужие разделы.

Минимальный английский файл:

```json
{
  "help": {
    "my mod": {
      "name": "My Mod",
      "description": "Adds a configurable adventure-map feature.",
      "hotkeys": {
        "name": "Hotkeys",
        "0": {
          "keys": "Ctrl+H",
          "name": "Open settings",
          "description": "Open this mod's settings on the adventure map.",
          "type": "ADV_MAP"
        }
      },
      "categories": [
        { "name": "Settings", "content": "Configure the feature in Lang/my_settings.json." }
      ]
    }
  }
}
```

В русском файле сохраните те же ключи, индексы и `type`, переведите `name`, `description` и `content`. Не переводите действия, имена ресурсов и код клавиш.

Все разделы необязательны. Если нужны только описание и горячие клавиши, не создавайте `categories`. Без `name` справочник покажет имя папки. Отсутствие статьи или хоткеев лучше, чем пустые либо выдуманные записи.

## Что делает справочник

- `description` добавляет раздел «Обзор».
- Непустой `hotkeys` добавляет раздел горячих клавиш **перед** авторскими статьями. Поэтому первая статья становится категорией 1; без хоткеев — категорией 0.
- `categories` содержит статьи с `name` и `content`.
- Раздел «Плагины» добавляется в конец, если в `EraPlugins`, `EraPlugins/BeforeWog` или `EraPlugins/AfterWog` есть `.era`, `.dll` либо `.bin`. Это список файлов, а не подтверждение их загрузки.

Хоткеи — только документация. JSON не назначает клавиши. Записывайте сочетания, которые реально обрабатывает ваш мод; указывайте необходимые опции и экран. Контексты: `EVERYWHERE`, `ADV_MAP`, `HERO`, `TOWN`, `COMBAT`, `MAIN_MENU`, `OTHER`. Для команд редактора явно пишите «Редактор карт»: в игровом окне они не работают.

Используйте последовательные индексы. Категории, хоткеи и сведения о плагинах читаются до 32 пропусков подряд или индекса 4095. Список `objects` заканчивается на первом элементе без `kind`.

## Кнопки, изображения и действия

Для обычной статьи достаточно `content`. В `objects` доступны `text`, `image`, `button`, `link`, `erm` и `ErmFunction`. Полный пример: [examples/help_authoring.json](examples/help_authoring.json).

```json
{
  "name": "Examples",
  "content": "",
  "objects": [
    { "kind": "text", "value": "Open an artifact card:", "overlay": 1, "x": 12, "y": 12, "width": 240, "height": 24 },
    { "kind": "button", "value": "Artifact", "action": "artifacts:7", "x": 12, "y": 44, "width": 180, "height": 30 }
  ]
}
```

Координаты относительны панели содержимого. Оставляйте промежутки между элементами. Изображения используют PCX либо группу 0 DEF; они не масштабируются. `zOrder` задаёт порядок создания. Для страницы с фиксированными элементами оставьте `content` пустым и используйте `overlay: 1` для пояснений, чтобы статья не перекрывала кнопки.

Действия:

| Значение | Результат |
| --- | --- |
| `creatures:0`, `artifacts:7`, `heroes:0`, `spells:15`, `skills:2`, `towns:0` | Карточка объекта с заданным ID. |
| `mod:my mod:1` | Категория мода; учитывайте раздел хоткеев в начале. |
| `search`, `guide` | Поиск или руководство. |
| `https://example.org` | Внешняя ссылка с подтверждением перед открытием. |
| `erm:MyFunction` | Вызов установленной ERM-функции без параметров; нужна запущенная карта. |

Кнопки срабатывают при отпускании ЛКМ. Портреты объектов и строки результатов поиска — при нажатии. Чтение JSON не запускает действий.

## Проверка и установка пакета сборки

Перезапустите игру после изменения JSON. Проверьте оба языка, название мода, статьи, контексты хоткеев и действия кнопок. Длинный текст должен прокручиваться. Не добавляйте хоткеи из документации другой версии мода без проверки.

`content/mod-help.en.json` и `content/mod-help.ru.json` содержат записи для WoG, ACM, GEM и TrainerX. Их источники перечислены в `content/mod-help-sources.json`.

Установка в игровую папку:

```powershell
.\ERA_HelpDialog\Install-ModHelp.ps1 -ModsRoot 'D:\games\HoMM 3 ERA\Mods'
```

Скрипт размещает каждую запись только в `Lang` соответствующего мода, английскую и русскую версии — под одинаковым именем. Для каждого мода используется отдельное имя `era_help_<мод>.json`, чтобы файлы не конфликтовали в VFS. Общие переводы интерфейса устанавливаются отдельно в WoG. Прежние файлы перед заменой сохраняются в `build/content-audit/backups`. Проверка без записи: добавьте `-WhatIf`.
