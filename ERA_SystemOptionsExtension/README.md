# ERA_SystemOptionsExtension

Настройки, доступные в окне плагина, хранятся в **`Runtime/era_system_options.ini`** относительно каталога игры. Окно настроек, API, параметры полоски здоровья, язык и кодировка используют общий механизм сохранения.

При запуске плагин читает сохранённые значения из `Runtime/era_system_options.ini`. Если значение отсутствует, для стандартной опции сохраняется уже загруженное игрой значение, а для дополнительной используется значение по умолчанию. Плагин не читает старые файлы настроек.

Открытие окна само по себе не вызывает запись. Изменения применяются сразу и сохраняются при закрытии окна; `SetOptionValue` сохраняет их сразу. При ошибке записи значения остаются активными, признак несохранённых изменений сохраняется для повторной попытки. Окно показывает сообщение об ошибке; API возвращает `-3`.

Если установлен обновлённый `ERA_LocaleManager`, выбор языка также вызывает общее сохранение. Плагин настроек восстанавливает язык и кодировку из `[Locale]` при запуске. Без плагина настроек LocaleManager сохраняет прежнее самостоятельное поведение.

## Секции файла

| Секция | Содержимое |
| --- | --- |
| `Settings.Extra` | Дополнительные опции из таблицы ниже |
| `Settings.Native` | Стандартные опции из таблицы ниже |
| `CombatHints` | `held`, `keyCode` (Windows virtual-key), `fillColor`, `lossColor`, `colorSaturation`, `yLabelShift` |
| `Locale` | `Language`, `CodePage` |

У полоски здоровья один сохраняемый флаг включения: `Settings.Extra.Combat.ShowCreatureHealthBar`. Цвета и насыщенность допустимы в диапазоне `0..1`, смещение — `-18..18`. Неверные числовые значения игнорируются. Ползунки включают обе границы диапазона; сброс сохраняет точные значения по умолчанию, включая `lossColor=0.975`.

## API

Экспорты с `__stdcall`: `GetOptionValue(const char*)`, `SetOptionValue(const char*, int)`, `SaveOptions()`. Типы и коды результата доступны в `headers/EraPluginsAPI/SystemOptionsAPI.h`.

`GetOptionValue` возвращает текущее настроенное значение или `-1` для неизвестного ключа. `SetOptionValue` ограничивает значение допустимым диапазоном и возвращает:

| Код | Значение |
| --- | --- |
| `1` | Опция изменена и сохранена |
| `0` | Значение опции не изменилось, несохранённые изменения успешно сохранены |
| `-1` | Ключ неизвестен или равен `nullptr` |
| `-2` | Изменение отклонено: очередь ходов/тип битвы во время боя либо включение звука без доступного драйвера |
| `-3` | Изменение действует в памяти, но запись не удалась; можно повторить `SaveOptions()` |

`SaveOptions` принудительно сохраняет общую конфигурацию и возвращает `BOOL`. Изменения через API отражаются в открытом окне и не перезаписываются устаревшим состоянием элементов при закрытии. Временные флаги быстрого завершения боя не сохраняются; изменение настроенных автозаклинаний через API во время временного переопределения переживает восстановление после боя.

| Ключ дополнительных опций | Диапазон | По умолчанию |
| --- | --- | --- |
| `Sound.AlternativeButtonClick` | `0..1` | `0` |
| `Sound.BackgroundLooping` | `0..1` | `1` |
| `Combat.QuickAutoResolve` | `0..1` | `0` |
| `Combat.BattleQueue` | `0..1` | `1` |
| `Combat.QuickCombatType` | `0..3` | `0` |
| `Combat.ShowCreatureHealthBar` | `0..1` | `1` |

Тип битвы: `0` — ручной, `1` — быстрый с заклинаниями, `2` — быстрый без заклинаний, `3` — спрашивать. Если значение не сохранено, используется ручной бой.

## Быстрое завершение боя

В бою человека против компьютера `Q` предлагает быстро завершить битву. Если включён `Combat.QuickAutoResolve`, кнопка «Автобитва» и её штатная клавиша `A` запускают тот же механизм без подтверждения. Он временно включает быстрый бой и отключает автозаклинания; исходные настройки восстанавливаются после боя. Реализация перенесена из WND, поэтому одновременно следует использовать сборку WND без старых обработчиков `Q`.

## Проверка в игре

Изменить настройки, перезапустить игру и проверить восстановление; вызвать API при открытом окне; проверить смену языка; проверить сброс и крайние положения ползунков; завершить битву через `Q` и через «Автобитву» с включённой/выключенной опцией. Отдельно проверить отказ от завершения боя, все четыре типа битвы, бой двух людей и сетевой бой. Сценарии требуют ручной проверки в игре.

## Текстовые ресурсы

Все тексты плагина находятся в установленном моде:

- `D:\games\HoMM 3 ERA\Mods\WoG\lang\era_system_options_dlg.json` — базовые английские тексты и резервный язык;
- `D:\games\HoMM 3 ERA\Mods\WoG\lang\ru\era_system_options_dlg.json` — русский перевод.

В этих файлах объединены тексты главного окна, настройки полоски здоровья и названия клавиш, мгновенного автобоя и ошибки сохранения. Они содержат ключи `era.opt.*` и `gem_plugin.combat_hints.text.*`; форматные параметры `%s`, `%d` и `@key@` должны сохраняться в переводах. Для другой установки игры используется та же структура `Mods/WoG/lang`.

Переводы редактируются и поставляются вместе с модом WoG. Дубликаты `lang` в проекте и дополнительные JSON `era_system_options_healthbar`, `era_system_options_quick_combat`, `era_system_options_storage` для этой установки больше не нужны.
