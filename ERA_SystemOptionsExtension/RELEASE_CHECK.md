# Проверка выпуска 1.6.0

Подготовлен кандидат на релиз. Изменения кода завершены; работа внутри игры ещё требует проверки.

## Выполнено

- Release/Win32: собраны `ERA_SystemOptionsExtension.era`, `ERA_LocaleManager.era` и `wog native dialogs.era`.
- Пройдены `SettingsSupportTests` и `QuickCombatStateTests` с включёнными проверками `assert` и `/W4 /WX`.
- Проверены экспорты API настроек, JSON переводов и отсутствие старых обработчиков быстрого завершения боя в исходниках WND.
- Возвращена полная перерисовка диалога HP при обновлении анимации существа.

## Проверка в игре перед окончательным выпуском

| Сценарий | Ожидаемый результат |
| --- | --- |
| Первый запуск с прежними INI | Создан `Runtime/era_system_options.ini`; перенесены значения, включая выключенные опции; `Settings.Version=1` |
| Изменение настроек и перезапуск игры | Восстановлены стандартные и дополнительные настройки, HP, язык и кодировка |
| Ручной бой, `Q`: отказ / подтверждение | Отказ сохраняет ручной бой; подтверждение завершает бой; исходные настройки восстановлены |
| «Автобитва» / `A`, мгновенный автобой выключен / включён | При выключенной опции штатный автобой; при включённой — мгновенное завершение против компьютера |
| Все четыре типа битвы; «Спрашивать» → ручной бой → `Q` | Режим следующего боя остаётся выбранным в настройках |
| Бой двух людей / сетевой бой | Штатное поведение; мгновенный автобой не включается для боя двух людей |
| HP: анимация, ползунки, крайние значения и сброс | Существо анимируется; окно перерисовывается полностью; настройки соответствуют выбранным значениям и сохраняются |
| Смена языка из настроек и через LocaleManager | Обновлены подписи и подсказки; после перезапуска выбранный язык восстановлен |
| API при открытом окне настроек | Новое значение видно в окне и сохраняется; очередь и тип боя отклоняются во время боя |

## Комплект обновления

Архив `Release/ERA_SystemOptionsExtension_1.6.0-rc.zip` содержит `EraPlugins`, `Lang`, документацию и `SHA256SUMS.txt`. Каталоги предназначены для обновления установленного мода WoG с существующими ресурсами диалогов. Замените существующие плагины соответствующими файлами из комплекта. Обновлённый WND нужен для переноса обработчика `Q`; обновлённый LocaleManager — для общего сохранения языка.

Пользовательский INI создаётся при первом запуске и в архив не включён. После успешной проверки сценариев в игре комплект можно выпускать как окончательный релиз.
