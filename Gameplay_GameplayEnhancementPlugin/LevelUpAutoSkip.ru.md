# Автопропуск повышений уровня в GEM 1.13.0

Если при входе в штатную проверку герой должен получить больше трёх уровней,
диалог получает две кнопки слева от обычной «ОК»:

| Кнопка | DEF | Действие |
| --- | --- | --- |
| Ближайшая к «ОК» | iOkay.def | Закрыть текущее окно и автоматически закрывать следующие после их отрисовки |
| Ещё левее | iCancel.def | Закрыть текущее окно и выполнить следующие повышения без создания диалогов |

При двух предложенных навыках выбирает штатный ИИ. При одном или отсутствии
навыков остаётся штатная обработка игры. Правая кнопка мыши на новой кнопке
показывает описание действия. Стандартная «ОК» сохраняет ручной выбор.

Порог относится к началу серии, поэтому обе кнопки остаются доступными после
нескольких ручных подтверждений той же серии. Режим сбрасывается при выходе из
CheckLevelUps; следующий герой и следующая серия снова начинают с ручного режима.
Вложенный вызов имеет отдельное состояние и восстанавливает внешнее.

В версии 1.13.1 после включения быстрого показа звук повышения уровня допускается
ещё один раз, на следующем повышении. Последующие окна этой серии показываются
без повторного запуска звука. Ручные повышения сохраняют звук на каждом уровне;
счётчик быстрого режима сбрасывается для каждой новой серии.

Функция включается вместе с `gem_plugin.modules.features`. Английские и русские
подсказки находятся в `lang/gem_level_up.json` и `lang/ru/gem_level_up.json`;
их нужно положить в одноимённые каталоги установленного GEM. Без JSON работают
английские подсказки из плагина.

## Подтверждённые точки подключения

Дизассемблирование экспорта IDA сопоставлено с байтами локального `h3era.exe`.
SHA-256 исполняемого файла:
`451E208CB2985BCA75330F0E3C52F89F9219C0C3701BC6E1F354217890C36181`.

| Адрес | Использование |
| --- | --- |
| 0x4DA990 | thiscall-обёртка всей проверки повышений |
| 0x4DAA3A | EBX — герой; EDX — рассчитанный конечный уровень до первого повышения, после обеих веток расчёта опыта |
| 0x4DAC91 | Начало подготовки аргументов звука: в быстром режиме после одного дополнительного запуска переход на 0x4DACA0, сразу после LoadWAVplayAsync |
| 0x4F8F10 | thiscall-конструктор диалога с героем, первичным навыком и двумя кадрами вторичных навыков |
| 0x4F9E10 | thiscall-обработчик сообщений диалога |
| 0x4F9DC0 | thiscall-деструктор: очистка ссылки на активный диалог |
| 0x4F9E67 | Образец штатного закрытия по таймеру: команда MOUSE_BUTTON, END_DIALOG, itemId=10, результат 9999 и сброс таймера 0x6977D4 |
| 0x4DAEAC | Результат 9999 передаёт выбор одного из двух навыков ИИ |
| 0x4DAC62 | Проверка 0x698450 перед созданием окна |

Количество повышений не вычисляется повторно в плагине. Флаг 0x698450 сохраняется
при входе и восстанавливается при выходе. Быстрый режим с окнами его не меняет;
скрытый режим использует штатную ветку игры с этим флагом, включая её параметры ИИ.

## Проверка

Собраны Debug/Win32 и Release/Win32. `Verification/LevelUpAutoSkip.tests.cpp`
подключает реальные обработчики с подставными игровыми объектами. Проверены:
порог 0–4, расположение и DEF кнопок, ручная обработка, локализованная подсказка,
обе серии пропуска с 0/1/2 навыками, второй герой и восстановление состояния при
вложенной проверке. Стенд не исполняет машинный код игры и не проверяет её ИИ.
Для 1.13.1 дополнительно проверены один дополнительный звук, включение режима
после ручных повышений, сброс лимита, вложенный вызов и другой герой.

Стенд собирается из каталога Verification в x86 Developer Command Prompt:

```bat
cl /nologo /std:c++17 /EHsc /W4 /WX /MT /Fe:build\LevelUpAutoSkip.tests.exe /Fo:build\LevelUpAutoSkip.tests.obj LevelUpAutoSkip.tests.cpp
build\LevelUpAutoSkip.tests.exe
```

Каталог build должен существовать. В сборках плагина остаются предупреждение
MSB8051 локального v141_xp и существующее C4018 в AdventureMapHints.cpp:541.

В самой игре ещё проверить: серии на 3 и 4 повышения, оба режима на длинной серии,
случаи с 0/1/2 навыками, последующую серию другого героя, обычные диалоги после
скрытого пропуска, стандартную «ОК», подсказки, HD и сетевую игру. Отрисовка и
совместимость с загруженными сторонними хуками пока не подтверждены игровым запуском.

## Локальная установка

13 октября 2026 года Release 1.13.0 установлен в
`D:\games\HoMM 3 ERA\Mods\Game Enhancement Mod\eraplugins\Gameplay_GameplayEnhancementPlugin.era`
после закрытия игры пользователем. Установлены оба языковых JSON, .map и .dbgmap;
хеши всех пяти файлов совпадают с результатами сборки и исходными JSON.
Прежние .era и .dbgmap сохранены в `Verification/build/previous-installed/`.

В тот же день установлена Release 1.13.1 с ограничением повторного звука.
Хеши .era, .map и .dbgmap сверены с результатами сборки. Копия установленной
версии 1.13.0 сохранена в `Verification/build/previous-installed-1.13.0/`.
Работу автопропуска версии 1.13.0 пользователь подтвердил в игре;
новое ограничение звука версии 1.13.1 пока проверено только стендом.
