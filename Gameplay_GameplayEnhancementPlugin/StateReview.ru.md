# Проверка состояния интерфейса, версия 1.11.3

Проверены активные модули ArtifactHints, GameplayFeature, GraphicsEnhancements,
ExtendedResourcesInfo, их запуск и общая обёртка временных патчей. Поведение
сопоставлено с исходниками до переработки. Для владения PCX и участков игровых
хуков проверены H3API и код установленного h3era.exe.

## Подтверждённые исправления

1. **Подсказка мифрила в обзоре королевства.** Штатный обработчик вызывался после
   установки текста и мог его перезаписать. Теперь он вызывается первым, затем
   подменяется только подсказка внутри области мифрила. При выходе в любом
   направлении действуют штатные подсказки. Обработанное нажатие правой кнопки
   не передаётся повторно; остальные нажатия сохраняют штатную обработку.
2. **Изменение чужого окна.** HideResources очищал мифрил в глобальном окне карты,
   даже когда получал ресурсную панель другого окна. Теперь используется
   GetParent() переданной панели, как для её обычных ресурсов.
3. **Освобождённый фон мифрила.** SetPcx присваивает указатель без увеличения
   счётчика ссылок; деструктор виджета снимает ссылку. Кэш оставался с указателем
   на освобождённый PCX. Create начинает со счётчика 0: теперь модуль держит свою
   ссылку, а каждый виджет — отдельную. При смене размеров создаётся новый фон,
   старые виджеты сохраняют свои ссылки. Деструктор модуля освобождает кэш.
4. **Старые указатели при повторном создании панели.** Перед выравниванием и
   созданием сбрасываются ссылки на прежние виджеты. Область подсказки привязана
   к окну владельца. Неполная панель отклоняется до изменения координат;
   при неудачном создании иконки доступна подсказка над текстом мифрила.
5. **Индикаторы городов в обзоре королевства.** Список читался без проверки
   смещения, числа городов и размера массива. При переключении на героев или
   исчезновении исходного элемента старый индикатор мог остаться видимым.
   Теперь индексы проверяются, неприменимые индикаторы скрываются, неудачное
   создание нового виджета не приводит к разыменованию nullptr.
6. **Раскраска пути на следующий день.** Поле регистра esi беззнаковое;
   проверка esi + maxMovement < 0 не срабатывала. Остаток движения теперь
   явно преобразуется к знаковому INT перед сложением. Штатный участок
   0x4190D9 добавляет 25 к кадру; для второго дня плагин добавляет 50
   и переходит к 0x4190DE без повторного выполнения штатной прибавки.
7. **Общий текстовый буфер при обновлении ресурсов.** Вспомогательная функция
   форматирования записывала число в h3_TextBuffer при каждой перерисовке.
   Теперь она возвращает собственный H3String и сохраняет общий буфер.

## Остальные проверенные места

В описаниях артефактов проверены восстановление высоты, контекста героя и слота,
вложенные окна и однократное использование дополнительных данных. Новых
подтверждённых ошибок этого класса не найдено.

Проверены сравнение имён DEF при добавлении Space, клавиатурный хук NumPad,
парные хуки временной кнопки сноса и границы возвращения в игровой код.
Выходы процедуры сноса возвращаются в обёртку, где снимается патч; ошибка
трактовки Apply как bool в этой паре отсутствует. Неиспользуемые обработчики
HeroFullMP_Rem и expFix.cpp не подключаются к текущей сборке.

## Проверки и пределы результата

Runner извлекает актуальные функции и тип ResourceBarInfo из исходников.
Модель PCX учитывает начальный счётчик 0, присваивание без AddRef и освобождение
ссылки виджетом, согласно H3API и игровому коду. Проверены повторные открытия,
неполная панель, смена размеров с живым старым виджетом, подсказки и чужие окна,
списки городов и знаковый остаток движения.

Контрольные прогоны с возвращением шести прежних дефектов завершаются ошибками
соответствующих проверок: владение PCX, окно панели, порядок обработки подсказок,
указатели виджетов, индикаторы городов и беззнаковая арифметика пути.

Debug и Release собираются. Файлы установки игры не изменяются. Проверки
отрисовки в ERA, взаимодействия с другими плагинами и горячих клавиш в живом
интерфейсе остаются необходимыми; изолированные проверки не заменяют запуск игры.
