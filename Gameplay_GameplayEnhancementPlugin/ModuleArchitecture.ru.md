# Модули GEM и описание артефактов

Gameplay_GameplayEnhancementPlugin и Interface_ArtifactsQuickSwitching остаются
двумя самостоятельными DLL. Их совместная поставка в GEM не требует объединения.

## Инициализация

DllMain подключает ERA и ставит отложенный обработчик. В HooksInit через настоящие
заголовки запускаются пять модулей. У каждого свой экземпляр патчера:

| Модуль | Экземпляр | JSON-флаг |
| --- | --- | --- |
| Графика и индикаторы городов | EraPlugin.GraphicsEnhancements.daemon_n | gem_plugin.modules.graphics |
| Общие улучшения | EraPlugin.GameplayTweaks.daemon_n | gem_plugin.modules.features |
| Ресурсы и мифрил | EraPlugin.ResourceBar.daemon_n | gem_plugin.modules.resources |
| Артефакты | EraPlugin.ArtifactHints.daemon_n | gem_plugin.modules.artifact_hints |
| Подсказки карты | EraPlugin.AdventureMapHints.daemon_n | gem_plugin.modules.adventure_hints |

Отсутствующие флаги означают true. Поддерживаются true/false и 1/0.
Флаги читаются при инициализации; изменение требует перезапуска игры.
Это не новый интерфейс переключения модулей во время партии.

Пример дополнения существующего JSON, без удаления его остальных настроек:

```json
{
  "gem_plugin": {
    "modules": {
      "graphics": true,
      "features": true,
      "resources": true,
      "artifact_hints": true,
      "adventure_hints": true
    }
  }
}
```

Существующие ключи, имена кнопок и ERM-переменные сохранены. Индикаторы городов
дополнительно требуют gem_plugin.building_hints.enable. Ресурсный модуль требует
hd_wog.dll и учитывает размеры экрана. Подсказки карты не инициализируются, если
экземпляр EraPlugin.AdventureMapHints.daemon_n уже создан другим плагином.

Временные патчи карты и окна сноса здания размещены в отдельных экземплярах
с суффиксом Transient.daemon_n: они не должны включаться через ApplyAll постоянных
патчей модуля. Общий экземпляр DLL остаётся для подключения и старта.

ScopedPatch учитывает контракт patcher_x86: Apply возвращает индекс патча >= 0,
включая 0 при успехе, а отрицательные значения означают ошибку. Патчи блокировки
отрисовки строки подсказок и игнорирования её фокуса снимаются при выходе из
GetHintText. Вложенный вызов сохраняет уже применённый патч внешнего вызова.
В версии 1.11.1 исправлена ошибочная проверка Apply как булевого результата,
из-за которой строка подсказок оставалась заблокированной после подписей карты.

Обработчик клавиши Alt явно различает KEY_DOWN и KEY_UP. Для остальных сообщений
состояние проверяется через GetKeyState(VK_MENU), старший бит 0x8000, и фокус окна
игры. Промежуточные сообщения без флага Alt не сбрасывают удержание клавиши.
При изменении состояния обновляется строка подсказок; фокус поля чата сбрасывает
сохранённое состояние Alt без принудительного обновления.

Исходный порядок работы: ProcMapScreen задаёт состояние Alt, SetHint показывает
стоимость пути вместо обычной подсказки при удержании Alt, а GetHintText временно
вызывает обычный SetHint для создания подписи объекта на карте. Последний вызов
должен возвращать текст через h3_TextBuffer, сохраняя содержимое хинт-бара.

В исходном патче переход 0x40D0F4 -> 0x40D136 отключал только отрисовку хинт-бара.
Игра уже отправляла текст в его виджет командой по 0x40D0DB, поэтому следующая общая
перерисовка показывала подпись объекта вместо очков движения. Ранее исправленная
маска 0x8000 сделала этот конфликт заметным при работе подписей карты по Alt.
В версии 1.11.2 переход перенесён на 0x40D0DB -> 0x40D136: временный вызов пропускает
запись текста и отрисовку. Само построение текста и завершение игровой функции
сохранены; после выхода патч снимается и обычная строка подсказок работает штатно.

## Межплагинный интерфейс артефактов

Общий контракт находится в headers/EraPluginsAPI/ArtifactDescriptionApi.h.
ArtifactHints публикует Api через переменную патчера GEM.ArtifactDescription.Api.1.
Потребитель проверяет magic, размер, версию и наличие функции.

Синхронный show получает указатели на героя и артефакт и целевой слот 0..18
(либо -1, если слот не выбран). Указатели принадлежат вызывающей стороне и не
сохраняются после вызова. Результат 1 означает, что описание показано, 0 — отказ.
При отсутствии API, несовместимой версии или отказе быстрый выбор вызывает обычное
игровое описание, поэтому остаётся работоспособным отдельно.

Контекст героя и слота восстанавливается после вызова, включая вложенные вызовы.
В штатном обмене героев контекст задаётся обработчиком соответствующего слота.
Если слот неизвестен, сравнение выполняется только при однозначном выборе;
при нескольких возможных слотах показываются собственные характеристики предмета.

Описание не меняет высоту следующих окон. Дополнительный текст и высота привязаны
к одному последующему сообщению с совпадающим описанием. Ограничения высоты меняются
при построении окна, восстанавливаются перед его обработкой и дополнительно
защищены восстановлением при выходе. Чужое сообщение сбрасывает ожидающие данные.

JSON-флаг gem_plugin.artifact_hints.primary_skills.enabled теперь учитывается;
ERM-переменные выбора игрока продолжают действовать. При true результат определяется
ERM-настройкой, при false блок характеристик отключён.

## Проверка

Полный аудит, изменения 1.12.0 и процедура сборки кандидата описаны в
[ReleaseReview.ru.md](ReleaseReview.ru.md).

Результаты повторной проверки остальных модулей и исправления версии 1.11.3
описаны в [StateReview.ru.md](StateReview.ru.md).

Перед выпуском проверить в игре:

1. Повторно открыть карту и города; прокрутить списки до конца, включая одного
   владельца с одним городом и интерфейс без дополнительных кнопок.
2. Проверить Alt, отпускание Alt, скрытую карту и подписи у краёв экрана.
   Для героев теперь применяется обычная текстовая подпись; экспериментальная
   недостижимая ветка с портретом удалена.
3. Проверить посещённые объекты за несколько игроков, включая последнего игрока;
   убедиться, что временное построение подсказок не меняет признаки посещения.
4. Проверить путь по воде в лодке, полёт, хождение по воде, недоступную клетку
   и недостаток движения. Доступность определяет игровой поиск пути.
5. Проверить описание деталей сборного артефакта без первичных характеристик,
   отдельно выключить статистику и external_widget, затем открыть обычное сообщение.
6. Проверить оба кольца и дополнительные слоты в быстром выборе и обмене героев;
   сравнение должно относиться к выбранному герою и выбранному слоту.
7. Проверить быстрый выбор отдельно, с новым поставщиком API и со старой версией
   второго плагина. Проверить свитки и вложенные окна.
8. Проверить мифрил на разных разрешениях и в обзоре королевства; Backspace не
   должен открывать подсказку. Проверить NumLock и цифровую клавиатуру.
9. Перезагрузить языковые данные и проверить подсказки карты и артефактов.

expFix.cpp остаётся исключённым из сборки. Его экспериментальные хуки не включены.
Измерение производительности подписей на насыщенной карте остаётся игровым тестом;
кэширование текста без учёта игровых событий здесь не вводилось.
