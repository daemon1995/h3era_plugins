Используются `../headers/header.h`, общий H3API и `../headers/Era/era.cpp`; локальный WoG_NPC.h сохранён для ABI порта. Debug|Win32 собран с v141_xp 28.10.2026, игровые проверки не проводились. Настройки вывода наследуются от репозитория: обычная сборка проекта может записать .era в WoG. Не запускайте его одновременно с оригинальным Game Bug Fixes. Сомнения и отличия описаны в `docs/GAMELOGIC_PORT_REVIEW.md`.

# Game Bug Fixes — перенос на H3API

Проект Visual Studio 2022 (Win32, `v141_xp`, C++17) для переноса оригинального **Game Bug Fixes by igrik** с `homm3.h`/старого ERA API на **H3API** и ERA из предоставленного `headers.zip`.

> **Статус: исходники портированы частично; это НЕ готовая и НЕ протестированная замена оригинального плагина.** Код не компилировался MSVC и не проверялся в Heroes3.exe / ERA. После первого переноса получены `h3era.exe` и две IDA-базы; для модуля MapSize теперь выполнена проверка исходных машинных инструкций по `h3era.exe`. Исходники `XXL(1).zip` получены и проверены на пересечения с текущим портом; подробности — `docs/XXL_COMPATIBILITY.md`. Некоторым хукам необходимы дополнительная проверка по дизассемблированному EXE и отладка в игре. Не устанавливайте результат поверх оригинального `Game Bug Fixes` без устранения конфликтов.

## Структура

- `Game_Bug_Fixes_H3API.sln`, `.vcxproj` — решение x86, выходной `Game_Bug_Fixes_H3API.era`.
- `third_party/H3API/single_header/H3API.hpp` — новый H3API (оригинал из `headers.zip`).
- `third_party/Era/era.h`, `era.cpp` — новый ERA API (оригинал из `headers.zip`).
- `third_party/WoG_NPC.h`, `include/WoGCrExpo.h` — специфичные для WoG ABI-структуры, не представленные в H3API.
- `src/Plugin.cpp`, `include/Plugin.h` — инициализация, регистрация инсталляторов модулей.
- `src/Fixes/` — перенесённые исходники (все включены как C++ единицы компиляции).
- `src/Ports/GameLogic.incomplete.cpp` — **черновик полной миграции GameLogic, исключённый из компиляции**, с нерешёнными вызовами старого API.
- `legacy/src/` — неизменённые оригинальные модули для построчного сравнения. В сборку не входят.
- `docs/migration_status.json`, `docs/legacy_hook_inventory.json`, `docs/ABI_MAPPING.md` — статус переноса, инвентаризация адресных патчей, сопоставления ABI.
- `docs/XXL_COMPATIBILITY.md`, `docs/h3era_mapsize_baseline.json`, `tools/compare_xxl_patches.py`, `tools/audit_xxl_compatibility.py`, `tools/verify_exe_mapsize.py` — проверка совместимости карт XXL, исходные сигнатуры в `h3era.exe`, сканер адресных пересечений и проверка EXE.

## Сборка

**Важно: Debug и Release Win32 используют `/Zp1` (`1Byte`) как оригинальный проект igrik.**
H3API самостоятельно применяет `/Zp4` и `/Zp1` к конкретным игровым структурам;
это не ошибка. Для WoG-структур введены отдельные `#pragma pack(push, 1)` / `pop`
и compile-time проверки размеров, выравнивания и смещений.
См. `docs/ABI_MAPPING.md`, `tests/check_packing.py`, `src/AbiLayoutChecks.cpp`.
Если компиляция останавливается на другом `static_assert`, нужен текст первой
ошибки MSVC: размер и имя структуры необходимы для безопасного исправления.


1. Откройте `Game_Bug_Fixes_H3API.sln` в Visual Studio 2022.
2. Установите платформу **Win32** и **Debug** или **Release**.
3. Убедитесь в наличии Windows 8.1 SDK и toolset **v141_xp**. При необходимости смените toolset на v143, если Windows XP не поддерживается.
4. Соберите проект. Отдельные перенесённые файлы **могут требовать исправления ошибок компиляции**, поскольку MSVC в рабочей среде переноса недоступен.
5. Проверяйте по одному модулю с `x32dbg`/IDA на соответствующей версии `Heroes3.exe`. Оригинальный Game Bug Fixes на время теста отключите.

По умолчанию устанавливаются старые базовые фиксы, новый `GameLogicCore` и `PrimarySkills`. Остальные исходники подключены к сборке, но их установка **заблокирована до проверки**. Для опытного тестирования добавьте в `Preprocessor Definitions` значение **`GBF_INSTALL_UNVERIFIED_PORTS=1`** (позволяет устанавливать дополнительные модули кроме MapSize; рекомендуется предварительно тестировать по одному).

**Для XXL:** исправления маршрутов WoG устанавливает XXL, а GBFE больше не содержит отдельного переключателя `GBF_INSTALL_MAP_SIZE_FIXES`. В `Graphics.cpp` устранено потенциальное дублирование обновления списка карт при обнаружении активного хука XXL на `0x580D40`. Подробнее — `docs/XXL_COMPATIBILITY.md`.

`Audio` содержит отдельную проверку возможности установки WoG/HD hooks и частичный rollback, но без проверки исходных инструкций это **не является защитой от всех конфликтов**.

## Что осталось

- Довести `GameLogic` до полного переноса: spell/attack pipeline, RNG, расширенный маршрут и обработчики GUI, вход/выход из менеджеров и т. д.
- Доделать `RoseKavalier` tooltip сказочного дракона и уточнить ранее частично перенесённые AI/Scouting хуки.
- Провести `sizeof`/`offsetof` проверки для всех WoG-структур, восстановить полный контроль x86 calling convention для каждого HiHook.
- Собрать MSVC Win32 и протестировать все адреса оригинального кода на **конкретной** сборке ERA с WoG, HD Mod и другими патчами.

Запуск `python tests/check_project.py` проверяет наличие файлов, корректность регистрации в проекте и инвентаризацию. Это **не компиляционный и не игровой тест**.

Эти изменения не изменяют настройки `/Zp1` и не отключают проверки `static_assert`.
Проверки проекта и сопоставление объявлений в предоставленном H3API выполнены;
**полная компиляция MSVC Win32 в этой среде недоступна**, а тесты запуска ERA не проводились.

При замене старой версии полностью обновите `src/Fixes/`, чтобы Visual Studio не продолжила компиляцию исходников из предыдущего архива.
