# Special terrain generation

`Erm_AddSpecialTerrainsEx(attempts, z)` is a `__stdcall` export invoked by WoG option 142. The caller supplies the number of attempts (0–100000) and map level (0 for surface, 1 for underground when present). It returns the number of objects added, or -1 when arguments are invalid, the service is unavailable, the map is unsupported, multiplayer is active, or allocation fails. A negative result can occur after some placements; it must not trigger a second pass. The distinct export name prevents a caller from using the old no-argument ABI with the new arguments.

The generator considers the game's catalog entries for types 21, 46, 222, 223, 224, 226–231. For the terrain at a randomly chosen coordinate it selects uniformly among compatible types, then uniformly among compatible subtype-zero flat prototypes, and prepares that exact DEF with the native loader. Underground coordinates are sampled from passable non-entrance land cells; after selecting a DEF, a cache indexed by its dimensions selects a location where the whole rectangle is free of rock and water. The current map and the full footprint are still rechecked before placement. Types and attributes are never rewritten. Each attempt places at most one prototype with the native WoG placement function. The caller determines the number of attempts independently for each level. Water, rock and maps wider than 256 cells are excluded. Every tile in a footprint must be on land allowed by the template (different permitted land types may meet), be passable in the template without entrances, and the footprint cannot overlap existing special-terrain objects (including favorable winds). At least one covered tile must be passable without an entrance. Other objects may overlap: the native flat/underlay flag controls drawing order. Placement is disabled in multiplayer because the standard placement packet does not synchronize the chosen DEF. Random placement does not guarantee equal distribution between players or a particular number of successful placements.

The original game lookup in the available Complete reconstruction recognizes 21 and 46 but does not list 223 or 230 as battle special terrains. The sample Arrogance map contains a flat 230 prototype; its effective behavior in the installed ERA configuration requires an in-game check. This API preserves those types and does not claim that their effects are identical.

After native placement the new object is identified by its appended details entry. Its drawing entry is moved to the beginning of each covered tile's object list, after first checking all affected tiles. This makes previously placed flat objects draw over the soil while retaining their relative order. The lists are part of the saved map state; behavior after loading and compatibility with other rendering hooks require in-game verification.
