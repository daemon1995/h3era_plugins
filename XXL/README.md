# XXL

Плагин перенесён из `JackSlater/XXL` в `H3EraPlugins.sln`. Использует общий
`../headers/header.h`, H3API, ERA и настройки сборки этого решения.
Оставлены работавшие в исходном плагине хуки размеров карт; отключённые
экспериментальные обработчики не подключаются.

Для новой **случайной или обычной карты** в дополнительных параметрах можно выбрать город,
а затем стартового героя ИИ обычными стрелками возле портрета. Герои, уже
выбранные другим игроком, пропускаются. Выбор передаётся загрузчику карты,
а не только отображается в диалоге. При случайном городе герой остаётся случайным.
На обычных картах учитываются ограничения автора: нельзя заменить фиксированного
героя; запрещённые и уже размещённые герои исключаются штатным списком игры.
При фиксированной фракции её тип берётся из маски доступных городов карты.

После успешного запуска случайной карты сохраняются только город, ID героя и бонус каждого цвета.
Параметрами генерации и таймерами занимается HD-мод; XXL их не сохраняет и
не восстанавливает. Прежняя секция `[RandomMap]` в INI игнорируется.
При открытии случайной карты в новом диалоге параметры выбора игроков
восстанавливаются один раз, поэтому последующие изменения пользователя не
перезаписываются. Запрещённые города, недоступные и повторяющиеся герои
не восстанавливаются. Неудачный запуск не заменяет настройки предыдущей игры.

Настройки хранятся в `Runtime/PluginSettings/MapSelection.ini` через Era API:
`ReadStrFromIni`, `WriteStrToIni` и `SaveIni`. Сохранение включено по умолчанию.
Чтобы отключить сохранение и восстановление, установите:

```ini
[XXL]
RememberSettings=0
```

Для сброса настроек удалите `Runtime/PluginSettings/MapSelection.ini`.
Предыдущий выбор не сохраняется и не
восстанавливается для обычных карт и сетевых партий. Кампании и загрузка
сохранений используют прежнее поведение.

В сетевой игре героев ИИ выбирает хост. Гости видят выбранных героев, но не
могут изменять их; пересланные гостем нажатия на стрелки ИИ также отклоняются.
Поддерживаются обычные и случайные карты, с теми же ограничениями автора карты.
Для сетевой игры установите одинаковую версию XXL у всех участников.
Синхронизация использует штатное сообщение `1039` длиной 2004 байта: заголовок
20 байт, 8 слотов людей и 8 слотов ИИ по 124 байта. После изменения хост
отправляет полное состояние через `NetworkSendData4(0x554950)` с теми же
флагами сжатия и доставки, что и штатный диалог дополнительных параметров.
Клиент получает слоты ИИ в `0x58BDCF..0x58BDE7`; отдельного формата пакетов нет.
Новая игра создаётся хостом, а гости загружают переданное им состояние через
штатный сетевой путь `0x589DF0`. Локальный INI в сетевой партии не применяется.

Из `HotAPatcher.exe` извлечён AutoIt-скрипт и разобран его машинный код:
сохранение города/ID героя/бонуса по цвету и восстановление ID через актуальный
список героев. Адреса HotA и запись патча в EXE не переносились. Новые места
хуков сверены с локальными `h3era.exe` и `h3era HD.exe`.

Цепочка выбора стартового героя:

| Данные | Адрес/смещение | Назначение |
| --- | --- | --- |
| Слоты людей / ИИ | Диалог + `0x1064` / `0x1444` | `selectedHeroIndex` + `heroes[]`; поиск слота человека по `player2` (цвет) |
| `startingHeroOfPlayer[8]` | `0x69FB80` | ID героев по цветам; передаётся в `LoadScenario(0x4C01E0)` и `GameMgr::StartNewGame(0x4BFB30)` |
| `playersInfo.heroMaybe[8]` | `H3Main + 0x1F844` | Выбранный стартовый герой игрока |
| `heroOwner[156]` | `H3Main + 0x4DF18` | Резервирование героя, исключающее его из случайного выбора других игроков |

Одного заполнения `0x69FB80` недостаточно. В `0x4BFC27` игра проверяет
`player.isHuman` перед резервированием выбранного героя и записью в
`heroMaybe`. В `LoadMap_CreateTownRandHeroes(0x4C9D00)` повторная проверка
человека в `0x4C9E03` заставляет ИИ игнорировать переданный массив и выбирать
случайного героя. XXL обходит обе проверки только во время запуска новой
случайной или обычной карты локально либо на хосте сетевой партии.
Остальные проверки, включая `-1` для случайного
героя, выполняет штатный код. Для случайного героя, размещённого на карте,
`0x50293D` читает `startingHeroOfPlayer[color]`, а `0x50294A` сбрасывает
использованную ячейку в `-1`.

Сборка: `XXL.vcxproj`, `Release|Win32`, локальный toolset `v141_xp`.
Результат — `XXL.era`, PDB и штатные MAP/DBGMAP. Для установки замените
`Mods/WoG/EraPlugins/XXL.era` при закрытой игре. Требуются графические ресурсы
размеров карт и переводы установленного XXL; они уже присутствуют в локальном WoG.

Проверки логики выполняются отдельной локальной программой из игнорируемого
каталога `verification/`: ABI, выбор героев людей/ИИ, конфликты, восстановление,
недопустимые настройки, INI и успешный/неудачный запуск. Отдельная регрессия
исполняет фрагменты машинного кода из локального EXE с настоящим `patcher_x86`:
без исправления выбранный герой ИИ игнорируется, с обоими хуками резервируется
и используется; случайный выбор и поведение человека сохраняются.
Формат сетевого сообщения и роль хоста/гостя проверяются отдельно, а перенос
слотов ИИ на клиента выполняется извлечённым из EXE штатным машинным кодом.
Проверка непосредственно в игре, включая живую сетевую партию, остаётся
необходимой: выбрать героя ИИ, запустить карту, проверить героя
на карте, затем открыть новую игру после перезапуска и сверить параметры.
