Плагин извлечён из `quickStart` в `Test_DifferentStuff/dllmain.cpp`.
Проект входит в `Commissions.sln`, наследует `Commissions/Directory.Build.props`
и общие настройки сборки. Выход: `$(LocalGamePath)/Mods/Random Combat Simulator/eraplugins/`.
После сборки содержимое `mod/` копируется в корень этого мода.

Кнопка регистрируется через `MainMenu_RegisterWidget` вне `DllMain`, в `OnAfterWog`.
Её обработчик ставит запуск в очередь. Хук процедуры главного меню передаёт штатное
нажатие «Новая игра» дальше по цепочке и возвращает результат закрытия диалога.
`FastQuitToGameMenu` используется только после боя: в главном меню его служебное
исключение не перехватывается и вызывает вылет.
Карта по умолчанию — `QuickCombat.h3m`. Поиск идёт по полному `mapsList`, без
фильтра размера. При отсутствии карты открывается обычный выбор сценария с сообщением.

`OnGameEnter` ставит бой в очередь; запуск происходит при первом сообщении активного
менеджера приключений. На каждый вход на карту (включая загрузку и рестарт) приходится
один бой. Новые параметры генерируются независимо от восстановленного seed карты.
Нападающий управляется текущим игроком, защитник — компьютером в одиночной игре.
Герои выбираются независимо без совпадения ID; армии, базовые характеристики, уровень,
навыки, заклинания, мана, мораль, удача и снаряжение случайны в заданных диапазонах.
По умолчанию героям выдаётся случайный опыт 0..18975933 штатной `GiveExperience`
с `checkLevelUps = TRUE`; движок сам рассчитывает уровень и повышает навыки.
На время вызова DWORD по адресу `0x698450` равен `TRUE`, затем его исходное
значение восстанавливается. Это подавляет диалоги повышения уровня.
Верхний предел опыта соответствует 50-му уровню; лимит уровня карты учитывается
движком. Диапазон опыта задаётся в `battle.experience` (вместо `battle.level`).
Количество разных надетых артефактов по умолчанию 0..14 — `battle.artifacts`.
Слоты выбираются в случайном порядке, один ID артефакта не повторяется у героя.
Если для слота нет доступного подходящего предмета, он пропускается. Книга
заклинаний и боевые машины не входят в это количество и имеют свои вероятности.
Окна информации о герое читают уровень и опыт из `H3Main::heroes` по ID, поэтому
эти два поля временно синхронизируются с боевой копией. После боя и при досрочном
выходе исходные уровень и опыт восстанавливаются вместе с остальным состоянием.
В журнале ERA плагин пишет параметры загруженной сборки и фактические уровень/опыт
обеих сторон перед боем, а также количество выданных артефактов.
Если на карте включена опция WoG 900 «Опыт существ», каждый обычный отряд обеих
сторон получает случайный опыт на одно существо от 0 до предела своего типа.
Проверяется текущая опция карты через `GetRealAddr`, включая состояния 2/3
(заблокировано выключено/включено). Опыт задаётся через `EA:E` в
`OnSetupBattlefield`, чтобы применить бонусы ранга к временным боевым отрядам.
Опыт армий настоящих героев не изменяется. При выключенной опции опыт не задаётся.

Бой идёт между копиями героев в `(0,0,0)`, тип почвы может случайно меняться на `0..7`.
Командиры отключены на время симуляции. Экран результатов сохранён, обработка потерь
и опыта на карте пропущена, чтобы не удалять настоящих героев и не вызывать конец игры.
После боя настройки быстрого боя, почва и командиры восстанавливаются. Восстановление
также вызывается при досрочном выходе из боя через `OnBeforeFastQuitToGameMenu`.
Ответ в диалоге ведёт в `FastQuitToGameMenu(PAGE_RESTART)` или `PAGE_MAIN`.

JSON: `mod/mod.json`, `mod/lang/random_combat_simulator.settings.json`,
английские тексты в `mod/lang/random_combat_simulator.json`, русские — в `mod/lang/ru/`.
Числа ограничиваются допустимыми диапазонами; перевёрнутые интервалы нормализуются.

`validation/MenuLaunchRequestTest.cpp` проверяет запуск при обоих возможных порядках
хуков API и плагина, возврат штатного результата закрытия меню, однократность запуска
и сброс очереди. Это автономный C++17-тест без запуска игры.
`validation/CombatParametersTest.cpp` проверяет диапазоны опыта и количества
артефактов, отсутствие повторов предметов, совместимость слотов, выбор всех
14 обычных слотов и поведение при нехватке подходящих артефактов.
