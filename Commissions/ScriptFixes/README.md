# Массовое ожидание и защита

Game Enhancement Mod/Data/s/Protection by all units in battle.erm устанавливается
в одноимённый мод. Кнопки уже описаны в Data/Buttons/gem_buttons.btn.
Исправлены регистр имён gem_allwait_Button_ID / gem_alldefend_Button_ID и защита
от сравнения с отсутствующими ID. Новый файл .btn не требуется.

Alt+W — ждать всеми, Alt+D / Alt+Space — защищаться всеми. Новый приказ заменяет
предыдущий. Режимы сбрасываются перед боем, после боя и на новом раунде;
ожидание также сбрасывается при переходе в фазу ожидания.
Учитываются локальный контроль, башни, боевые машины и gem_control_units.

Требует проверки в игре: кнопки, горячие клавиши, новый раунд, уже ожидавшие
отряды, гипноз/берсерк, автобой, локальный PvP и сетевой бой.
