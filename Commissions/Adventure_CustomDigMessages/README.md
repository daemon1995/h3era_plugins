# Adventure_CustomDigMessages

Пункт 7: три сообщения штатного копания — нехватка хода, подтверждение и пустая находка.
Скопировать lang/mrart_dig.json в Mods/Commissions/lang и плагин .era в eraplugins.

EraJS читает mrart.dig.messages.<insufficient|confirmation|empty>.text и .color.
color — индекс H3 eTextColor (0..31); dialog_width задаёт ширину окна.
Высота определяется количеством строк текста.

Для отдельной клетки можно переопределить любой текст и цвет по ключу
mrart.dig.tiles.<x>_<y>_<z>.<вид сообщения>.<text|color>, например
mrart.dig.tiles.20_30_0.empty.text. Координаты нулевые, z=0/1.
Отсутствующие свойства берутся из общих messages.

Штатная функция 0x40EBF0 сохраняет проверки хода, рюкзака, воды и доступности
почвы, выдачу Грааля, создание ямы, очистку маршрута и расход хода.
Подтверждение перехватывается только для человека после всех проверок, до
звука и создания ямы. При отмене ходы и карта не меняются.

Адреса подтверждены экспортом H3SodIdaExport и дизассемблированием установленного
h3era.exe: нехватка хода 0x40EC77 → 0x40ECA3; подтверждение 0x40EE79;
пустая находка 0x40F05A → 0x40F080. В точках перехвата аргументы ещё не помещены в стек.

Проверено: Debug/Release Win32. Для проверки в игре: полный/неполный ход,
подтверждение/отмена, вода, занятая почва, полный рюкзак, пустая клетка,
Грааль и переопределение JSON для конкретной клетки.
