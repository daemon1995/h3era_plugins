# Combat_CreatureSpellSelector

ERA-перенос выбора заклинаний для джиннов (37), сказочных драконов (134) и чародеев (136).
Проект включён в Commissions.sln вместо незавершённого Combat_CasterCreatureSpellSelector.

В окне активного существа доступна штатная кнопка заклинания. Ctrl+ЛКМ открывает
выбор непосредственно на поле боя. Кнопка D возвращает случайный выбор,
«Отмена» сохраняет прежнюю настройку. Чародей получает диалог перед автокастом.
Настройки очищаются при подготовке и завершении боя.

Списки и адреса сохранены: джинны используют friendlyMass; таблицы драконов и
чародеев читаются через указатели 0x447252 и 0x447D2C, по восемь записей.
Учитываются ограничения ландшафта, Сфера запрещения и Плащ отречения.

Скопировать lang/mrart_spell_selector.json в Mods/Commissions/lang, а собранный
Combat_CreatureSpellSelector.era — в eraplugins этого мода. Старую сборку
Combat_CasterCreatureSpellSelector одновременно загружать нельзя: она использует те же хуки.

EraJS читает ключи mrart.spell_selector: ctrl_click, prompt_enchanter, spells_def,
random_hint и priority.<id существа>. Приоритет — строка ID заклинаний через запятую.
Названия и описания заклинаний берутся из текущих игровых таблиц.

Проверено: сборки Debug и Release Win32. Требуется проверка взаимодействия с другими
модами в игре, включая сетевую игру, Ctrl+ЛКМ, обычную кнопку и автокаст чародея.
