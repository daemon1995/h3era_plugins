# Objects_DynamicHeroTeleport

Экспорты stdcall:

- DisplayObjectList(DWORD* packedPositions, int count, DWORD currentPosition):
  список по 8 строк на страницу; возвращает индекс в исходном массиве (с 0),
  либо -1 при отмене. Поддерживает стрелки и колесо мыши. Исключает текущую
  позицию, UINT_MAX и повторы. Позиция (0,0,0) допустима.
- DisplayTeleportSelector(DWORD* objectIndexes, DWORD currentObjectIndex):
  прежний интерфейс восьми направлений и квадрантов; результат
  `(direction << 16) | quadrant`, обе части с 1; отмена -1. Ноль означает
  недоступное направление. Этот контракт сохранён для прямых вызовов карты.
- DisplayHeroTeleporter: прежний совместимый вызов восьми направлений.

Data/s/mr_art custom_scripts.erm использует DisplayObjectList при посещении
объекта 63/61: все посещённые и видимые телепорты, кроме текущего, передаются
как H3Position (x | y<<16 | z<<26). После выбора герой переносится HE:P.
Тестовая функция mrart_TestTeleportSelector сохранена, автоматические привязки
к клавишам 1..5 удалены, чтобы не перехватывать горячие клавиши карты.

lang/mrart_script_text.json содержит имена и изображения. Расширения PNG
соответствуют файлам в установленном моде; проверено наличие всех ресурсов.
Для окон направлений высота ограничена высотой экрана, миникарта и квадранты
масштабируются вместе. При выборе квадранта меняются изображение и размер рамки.

Проверено: сборки Debug/Release Win32, ссылки на изображения и JSON.
Игровая проверка: отмена, пустой список, более 8 объектов, повторяющиеся позиции,
исключение текущего телепорта, фактический перенос и разрешение 800×600.
