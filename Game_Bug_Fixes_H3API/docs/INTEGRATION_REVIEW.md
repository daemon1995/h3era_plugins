Release не проверялся.

## Совместное использование и дубли

- Исходный Game Bug Fixes и этот порт устанавливают многие одни и те же исправления. Не загружать их одновременно: до полной миграции нужно решить, какие исправления остаются в оригинале и какие исключаются из него либо из порта. Частичная миграция не позволяет просто заменить оригинал без потери функциональности.
- По уточнению пользователя `UndoAllAt(0x5641A4)` работает как требуется. Повторная запись Graphics и Graphics_LegendaryHeroes остаётся вопросом дублирования.
- Пользователь убрал пересекающиеся звуковые хуки.
- Graphics.cpp:788 дополнительно обновляет выбранную карту после вызова 0x580D40 и содержит проверку старого XXL. В актуальной папке XXL не найден обработчик 0x580D40, на котором основано прежнее заключение docs/XXL_COMPATIBILITY.md. Повторно проверить поведение и актуальный набор модулей, прежде чем удалять эту защиту или включать Graphics. Сохранённый отчёт относится к прежним исходникам XXL.
- Сканирование буквальных адресов по исходникам репозитория обнаруживает кандидатов, но не проверяет пересечения диапазонов, косвенные адреса и динамические патчи HD/WoG. Само совпадение адреса не всегда означает конфликт; перед удалением проверить порядок установки, цепочку и семантику.
