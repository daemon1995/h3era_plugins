# Меню карт и ГСК

`mapselection::Init` — единая точка подключения меню, включая существующие
элементы `RMG_SettingsDlg`. Модуль устанавливается при загрузке CrBanks.txt.
Управление размерами, шаблонами и игроками перенесено из XXL. Обновлённый XXL
содержит только исправления миникарты и её ввода; эти два плагина нужно обновлять вместе.

## Возможности

- Кнопки H (180), XH (216), G (252), фильтры списка карт, значки и подписи размеров
  устанавливаются без проверки наличия XXL. 252 — наибольший стандартный размер
  с шагом 36 в пределах байтовой координаты карты.
- Ограничения активного шаблона учитывают раздельные интервалы его блоков,
  поверхность/подземелье и острова. Недоступный размер нельзя выбрать.
- Список шаблонов оформлен как раскрывающийся список с поиском, прокруткой и
  рамкой наведения; размеры окна союзов зависят от числа игроков, а кнопки
  подтверждения и отмены совпадают с диалогом настроек RMG.
- Окно города/героя использует размеры ячеек `itpaDef`, синие панели в три и
  четыре столбца без общего фона и страницы по 20 портретов. Страницы меняются
  колесом мыши или клавишами Page Up/Page Down. Всего допускаются
  все кандидаты, найденные штатным циклом по 156 героям.
- ПКМ на портрете вызывает исходный предпросмотр HD_WOG, ПКМ на городе — штатное
  окно состава города. Escape закрывает окно. Выбор применяется при нажатии,
  отпускание выбранного героя закрывает окно.
- Стартового героя ИИ выбирает локальный пользователь/хост с учётом ограничений карты.
  Авторский фиксированный герой не заменяется. Уже выбранные другими игроками
  герои скрываются из списка.
- Оригинальные элементы `computer only` (306–315) скрыты и отключены;
  их программные нажатия отбрасываются.
- Сохранение города, ID героя и бонуса перенесено из XXL. Совместимость с прежним
  `Runtime/PluginSettings/MapSelection.ini`, включая `[XXL] RememberSettings=0`,
  сохранена. INI применяется только к локальной новой случайной карте, один раз
  при открытии настроек. Неудачный старт не заменяет сохранённый выбор.

## HD и принадлежность хуков

Это перенос управления меню с адаптером к установленному HD_WOG, а не автономная
копия всего HD-мода. HD продолжает предоставлять создание базового расширенного
интерфейса, браузер папок/карт, таймеры, каталог и загрузку шаблонов, применение
союзов/типов дорог при генерации и свои сетевые уведомления. RMG владеет входом
меню, новыми диалогами, обработкой дорог, кнопками размеров и выбором игроков.
Без HD подключается обработчик выбора города и героя, но предпросмотр героя,
каталог шаблонов и применение шаблонов, союзов и дорог пока требуют HD.

Для актуальной предоставленной DLL проверены:

```text
HD_WOG.dll SHA-256 D29DFFE0DB94B8B03988D9B1EFC2D6DE1FCF0B698E60CC9085AC62D97DB9AF1A
PE timestamp 0x6ADDE7AD; SizeOfImage 0x2B1000; preferred base 0x10000000
```

Прямые адреса HD вычисляются как фактическая база + RVA. Адаптер проверяет
заголовок и сигнатуры кода до изменений; на несовпадающей DLL замена меню
не устанавливается и оставляет запись в журнале ERA. Проверка повторяется
в конструкторе меню, если HD ещё не закончил подключение `HD.TE`.

| Точка | Изменение |
| --- | --- |
| EXE `0x587FD0` | Снимается только HiHook владельца `HD.TE`; входом владеет RMG. Остальные обработчики остаются в цепочке. Для не заменённых возможностей вызывается исходный обработчик HD с актуальным `GetDefaultFunc`. |
| EXE `0x586103`, `0x5854BE` | Снимаются только дублирующие LoHook `HD.TE`; фильтрацией размеров и пропуском строк папок занимается перенесённый код XXL. |
| HD RVA `0xA1920`, `0xA1FD0` | Окна шаблонов и союзов заменены окнами RMG; применение и уведомления продолжаются по вызывающему пути HD. |
| HD RVA `0x97180` | Вызывается исходный предпросмотр героя. |
| HD RVA `0xA2920`, `0xA2F60`, `0xA2F80` | Нормализация размера, соответствие кнопкам и обновление ограничений; находятся по сигнатурам. |
| EXE `0x583D92` | Сбор полного списка кандидатов; штатные проверки доступности выполняются до этой точки. |

Замена группы хуков меню транзакционная: при ошибке новые патчи уничтожаются,
снятые патчи возвращаются на прежние позиции. Остальные хуки HD глобально не отключаются.
DLL на диске не изменяется.

## Более 16 героев и сеть

Размер `H3ScenarioPlayer` остаётся `0x7C`, поле `heroes[16]` остаётся массивом
32-битных ID. В отдельном массиве RMG хранится полный список. В точке `0x583D92`
первые 16 кандидатов заполняют штатное окно, остальные добавляются только в список
RMG; переход на `0x583DAA` продолжает штатный перебор вместо остановки на 16.
Выбор за пределами окна помещает ID в ячейку 15, а `selectedHeroIndex` получает 15.
Штатные чтение героя, его резервирование, запуск и сетевое копирование видят этот ID.
Байтовая переупаковка поля и расширение сетевой структуры не нужны.

Общий снимок выбора передаётся штатным пакетом 1039 размером 2004 байта.
Для прямого выбора города/ID героя гостем используется запрос RMG `0x524D4701`
размером 32 байта: заголовок 20 байт, цвет, вид выбора, значение. Хост проверяет
размер, отправителя против владельца человеческого слота, ограничения карты,
кандидатов и дубли. ИИ и чужой человеческий слот гостю недоступны. После запроса
хост отправляет снимок; гости не применяют неподтверждённый выбор локально.
**Всем участникам нужна одинаковая версия RMG.**

Окна RMG принимают изменения выбора игроков во время показа. Чат, служебные
сообщения и прочие уведомления ждут в очереди. Запуск игры,
отключение участника и изменение карты/вкладки закрывают окно
и возвращаются в основной цикл через перехват `0x5547F0`, с сохранением владения
памятью пакета и порядка доставки. Общими параметрами управляет хост; пересланные
нажатия новых кнопок XXL также отбрасываются на хосте.

## Сравнение с HotA

Изучены копии `HD_WOG 5.5 R71.dll.idb` и `HD_HOTA 5.7 RC12.dll.idb` через
консольный Hex-Rays, а ключевые процедуры повторно декомпилированы из актуальной DLL.
Общие для ERA части — выбор шаблона, команды по цветам, три дорожных флага,
проверка хозяина слота и обработка сетевых изменений в модальном окне — учтены.
Нельзя переносить адреса из HotA: её база `0x01000000`, функции и часть ABI отличаются.

HotA также интегрируется со своими зеркальными шаблонами, перечнем известных
шаблонов по контрольным суммам, пулами героев таверны и собственными фракциями.
Эти механизмы зависят от HotA и не включены в ERA как произвольные патчи.
Исследованный диалог HotA тоже создаёт 16 обычных портретов; расширение RMG
реализовано отдельно через полный список и штатное сетевое окно.
В предоставленном snapshot `Heroes_ChangeStartingParameters` установка старого
меню находится после безусловного `return EXEC_DEFAULT`; его байтовое чтение
`heroes` не является контрактом действующей HD_WOG.

## Сборка и проверка

Оба проекта: `Release|Win32`, `v141_xp`; вспомогательный MapToDbgmap — `v143`.
Проверочные артефакты находятся в
`C:/Users/dimon/Documents/ChatGPT/H3SodIdaExport/MapSelection/{rmg,xxl}/bin`,
рядом имеются `DebugMaps` и журналы сборки.

Локальные проверки вынесены за пределы репозитория: 206 проверок выбора/сети/INI
и 166 проверок реального образа HD, масок шаблонов, очереди пакетов и цепочки patcher_x86.
Вторая группа проверяет снятие только `HD.TE`, сохранение чужого обработчика,
отказ на неизвестной версии и отсутствие двойного вызова исходной процедуры.
Проверки запуска героев ИИ исполняют соответствующие инструкции установленного EXE.

Это не проверка интерфейса в игре. Ещё нужны визуальная проверка ресурсов и
живые партии хост/гость: одновременно выбрать одного героя, изменить город,
выбрать героя ИИ, сменить шаблон и союзы, отключиться и запустить карту при открытом
окне другого участника. Для установки заменить обе `.era` при закрытой игре
и скопировать `lang` в `Mods/WoG/Lang`; графические ресурсы размеров берутся
из уже установленного набора XXL.
