# Хижины провидцев

Страница `ePageSeerHut` (9) следует за пандорками. Горячая клавиша — `0`.
Категории: золото, опыт и существа. Одна строка соответствует одной награде;
карусель этой строки показывает все определения графики типа 83, независимо
от подтипа. Повторные генераторы одной награды не добавляют повторные изображения.

JSON использует те же поля, что и пандорки: `enabled`, `map`, `zone`, `value`,
`density`, а также `name` для подписи. Префиксы:

* `RMG.objectGeneration.83.gold.<количество>`
* `RMG.objectGeneration.83.experience.<опыт>`
* `RMG.objectGeneration.83.monsters.<ID существа>`

Начальные значения наследуются от общей записи `83/0`, затем применяются
параметры награды. Ценность генератора `value` не является размером награды.
Для существ стабильный ключ содержит ID существа, независимо от расчётного
количества существ и их текущей AI-ценности.

Пример: [examples/seer_huts.json](examples/seer_huts.json).
INI находится в `Runtime/RMG_CustomizeObjectsProperties.ini` и хранит только
отличия от JSON и нативных значений. Примеры секций:

```ini
[83_0_gold.5000_0]
map=4
zone=1

[83_0_experience.10000_0]
enabled=0

[83_0_monsters.4_0]
density=20
```

Параметры награды применяются ко всем её реальным графическим подтипам.
Лимиты карты и зоны суммируются по всем подтипам этой награды. Зональный
лимит проверяется в зоне размещения хижины, которая может отличаться от зоны
её квестового артефакта. Общие лимиты типа 83 продолжают действовать.

В API добавлены `SEER_HUT_GOLD`, `SEER_HUT_EXPERIENCE`, `SEER_HUT_MONSTERS`.
`ObjectKey` содержит `type=83`, `subtype=0`, размер награды или ID существа
в `first`, нули в `second/third`. `settingsSubtype` — внутренний индекс награды;
для сохранения идентичности следует использовать `ObjectKey`. Прежние номера
страниц и вариантов API сохранены.

## Исследование генерации

Проверен `D:/games/HoMM 3 ERA/h3era.exe`, SHA256:
`451E208CB2985BCA75330F0E3C52F89F9219C0C3701BC6E1F354217890C36181`.
Использованы локальные IDA-экспорты и проверка байтов установленного EXE.

`0x539000` создаёт полный набор наград для каждого подтипа хижины:
существа, золото 5000/10000/15000/20000 и опыт 5000/10000/15000/20000.
Таблицы генераторов: `0x640C10`, `0x640C1C`, `0x640C28`.
Нативные генераторы сохраняются: их `GetValue` проверяет текущий подтип
по полю `rmg+0xF58`, которое переключается после успешного размещения хижины.

Предварительный вызов генератора для диалога получает один служебный элемент
в списке прототипов типа 83. Нативный цикл проверяет только размер этого списка,
не разыменовывая элементы. Это создаёт один набор наград для регистрации;
вся графика подключается отдельно из настоящих определений объектов.
Без этого элемента пустой предварительный список полностью пропускает хижины.

Создание наград выполняется в `0x535080`, `0x5351B0`, `0x5352A0`.
Каждая функция возвращает `H3RmgQuestArtifact`; сама хижина находится
в его поле `seer` по смещению `0x20`. Вариант для счётчиков связывается с
хижиной, а не с этим артефактом. `0x54B980` размещает хижину в подходящей зоне;
проверка лимитов передаётся в `0x5475C0`, до изменения карты.

Автономные проверки и сборка не заменяют проверку диалога и генерации в игре.
