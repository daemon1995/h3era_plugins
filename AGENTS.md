# ERM 2.0 для ERA

В индексах локальных массивов именованные локальные переменные и константы пишутся без круглых скобок: `active[source]`, `active[CONST_NAME]`.

Правильно: `!!VR(active[source]):Sv1;`
Неправильно: `!!VR(active[(source)]):Sv1;`

Это правило относится к записи внутри `[...]`; внешние скобки именованного массива в команде сохраняются.

Для отключения ERM-кода разрывай первые два символа маркера ресивера, триггера или инструкции. Обычно заменяй первый `!` на `*`: `!!VR` → `*!VR`, `!?FU` → `*?FU`, `!#VA` → `*#VA`. Простого добавления `*` в начало строки недостаточно: исходная пара символов остаётся активной. Это относится и к примерам синтаксиса внутри ERM-файлов.
